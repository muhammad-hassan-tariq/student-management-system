# Student Management System

A full-stack web application for managing student records. The application allows users to add, view, update, delete, and search student information through a React frontend connected to a Node.js/Express REST API and Microsoft SQL Server database.

## Features

- Add new students
- View all students
- Update student information
- Delete students
- Search students by name, email, or program
- Display total number of students
- Form validation
- Success and error messages
- Responsive user interface
- RESTful API
- SQL Server database integration
